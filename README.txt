CURE COMMENT DATE PRIORITY — v65

ROOT CAUSE
- Existing Firebase records already contained an incorrect curePendingSince
  generated by an older version from updatedAt.
- v64 stopped writing new bad values, but those old stored values still took
  priority over the real date written in Commentaire.

FIX
- For CURE 1 / CURE 2, the matching date written in Commentaire is now checked
  first.
- Only when no matching CURE date exists in Commentaire is curePendingSince used.
- Parser accepts variants such as:
  * 1er CURE le 23/07/2026
  * 1er cure le 23/07/2026
  * 1er CURE + SMS le 23/07/2026
  * 2e / 2eme / 2ème CURE
- Header badge, overdue grouping and sorting all use the same corrected engine.

EXPECTED FOR THE SCREENSHOT
- CURE dated 23/07/2026 is overdue from 27/07/2026 at 00:00 Brussels time.
